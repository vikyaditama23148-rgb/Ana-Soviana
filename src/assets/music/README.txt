Letakkan file musik Anda di folder ini (satu file saja sudah cukup).
Format yang didukung: .mp3, .ogg, .wav, .m4a, .aac, .flac
Contoh: src/assets/music/lagu-ana.mp3

Setelah file ditambahkan, jalankan ulang "npm run dev" (atau "npm run build").
Tombol musik akan muncul otomatis. Jika folder ini tidak berisi file audio,
tombol musik disembunyikan dan website tetap berjalan normal.

Gunakan hanya musik yang Anda miliki hak penggunaannya.
